## 4. Glossary

Words that code comments, recorded fields and file names in this repository use:

| Term | Meaning |
|---|---|
| `coordinator` | the role that took the recorded decisions of our work (which candidate to build, which rule applies, what is uploaded). Pinned code comments and recorded fields keep the word as they ran; the documents say “we” |
| `vault`, private notes | our working notes, which are not part of this repository; times and texts quoted from them are marked “private notes” |
| `F1` to `F4`, `R3` to `R19`, `VAR-1` and similar | names of our work streams in the working notes and in pinned code comments; they say which stream wrote a script, not that another party did |
| queue numbers (`514`, `531`, `570`, `581`, `590`, `592`, `594a`, `594b` and others) | numbers we gave to built files before an upload: v35 = 514, v36 = 531, v37 = 541, v38 = 560, v39 = 542, v40 = 580; 570 = v36's configuration with the L3 legs on the public-phase input; 581 = v36's configuration on the final input, January and July rows in the daily format; 590 = the first final file (v35's configuration); 592 = v36's configuration on all four months (the default of the merge checks of section 14.7); 594a and 594b = the row-split builds Ba and Bb; 596 = v36's configuration with the L3 legs on all four months, 597 its January and July rows in the daily format, 598b = Bb on the L3 legs; 594c and 598c = 594b and 598b with the stage-1 tables of gate 1.9 (variant BbF) |
| `Ba`, `Bb`, `BbF`, `D`, `A` | corrector-stage merges by row group (January and July / February and June without an ADS-B match / with one): Ba = T 0.75, L 0.75, L 0.75 (chosen first, then dropped); Bb = T 0.75, L 0.75, L 0.5 (the final form); BbF = Bb with the four-month L run on the stage-1 tables of gate 1.9 (the final file); D = T 0.75 in all three groups (a null merge, used as a check); A = T 0.75, T 0.75, T 0.5 (a comparison build). T and L are the two forms of stage 2 of the corrector (section 14.7) |
| spec tags | the tag of a file is the tag of its input plus the suffix of the step that wrote it, so a tag spells its chain: the blend tag (for chain A `m6r27wincbrmfw4sv434`: legs, learners and seed counts), `tmc` (TabM added), `adsbgeondctxv3x50w` (the corrector: stage 1 on the ADS-B and stand tables, stage 2 on context table v3, with its settings), `s75` (scale2 0.75), `m4` (stage 2 fitted on four months), `c3` (three corrector seeds averaged), `r<variant>` (a row-group merge), the step suffixes of section 8 (`am`, `fh`, `gkc`, `x`, `ncr`, `db`, `aw`, `gp`, `gl`, `gja`), `avskap` (the average of the three chains) and `ff<k>` (the k-th final-format file built from it) |
